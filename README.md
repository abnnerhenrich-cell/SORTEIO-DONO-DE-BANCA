# Sorteios da Kelly — Dezenas e Centenas

Estrutura pronta para GitHub Pages:

- `/dezenas/` = sorteio de dezenas de 00 a 99
- `/centenas/` = sorteio de centenas de 000 a 999
- uma página entra na outra pelo botão de rota
- `index.html` redireciona automaticamente para `/dezenas/`

## Como subir no GitHub

1. Crie um repositório.
2. Envie todos os arquivos e pastas deste pacote.
3. Vá em Settings > Pages.
4. Em Source, escolha Deploy from branch.
5. Selecione branch `main` e pasta `/root`.
6. Salve.

Se o repositório for `sorteios`, os links serão parecidos com:

- `https://SEUUSUARIO.github.io/sorteios/dezenas/`
- `https://SEUUSUARIO.github.io/sorteios/centenas/`
